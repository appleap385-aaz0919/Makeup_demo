가상 메이크업 서비스 기획 메모

확정된 방향
- 사용자가 촬영하거나 업로드한 정지 사진에 메이크업 효과를 적용한다.
- 조명, 카메라 보정, 촬영 당시 피부색은 사용자가 판단한다. 서비스는 원본 사진을 기준으로 효과를 적용하며 별도의 촬영 환경 보정을 하지 않는다.
- 브랜드나 제품별로 구분하지 않고 자체 가상 색상표를 설계한다.
- 자체 가상 색상표를 넓은 색상 계열로 구성하며, 현재 색상 개수와 계열은 아래 항목을 따른다.
- 기본 기능은 파운데이션 색상 선택, 립스틱 색상 선택, 블러셔, 전후 비교, 실행 취소, 결과 저장이다. 파운데이션은 강도 조절 없이 동일한 합성 비율로 호수만 비교하며 나머지 컬러 기능은 적용 강도를 조절한다.
- 아이라이너는 검정색 ON/OFF와 두께·꼬리 길이·색상 진하기를 제공한다. 눈꺼풀 윤곽을 따라 끝이 가늘어지고 경계가 부드러운 마스크를 합성한다.
- 아이라이너 최대 두께와 진하기를 늘리고, 꼬리 방향을 -35도(아래)~45도(위)로 조절한다.
- 아이섀도는 팔레트 색상 선택, 적용 강도, 미적용으로 제공한다. 토글만 제공하지 않는다.
- 아이섀도는 눈두덩이 상하 폭과 좌우 폭을 각각 조절한다. 경계를 흐리게 만든 뒤 눈 안쪽 영역을 제외해 눈으로 색이 번지지 않도록 처리한다.
- 애교살은 ON/OFF, 진하기, 위치 미세 조절을 제공한다. 사진의 눈 아래 명암을 위치 추정에 활용하며, 신뢰도가 부족하면 눈 아래 윤곽 기준으로 배치한다. 전용 검출 모델이 아니므로 원래 애교살과의 정확한 일치는 보장하지 않는다.
- 눈 화장 탭 안에서 아이섀도 / 아이라이너 / 애교살 / 렌즈 메뉴를 나눠 선택한다. 메뉴 전환과 기능별 초기화는 다른 눈 화장을 유지한다.
- 상위 메뉴는 피부 / 립스틱 / 블러셔 / 눈 화장 / 헤어 5개를 유지한다. 피부 안에 파운데이션·점을, 눈 화장 안에 아이섀도·아이라이너·애교살·렌즈를 배치한다.
- 립스틱 48색, 블러셔 36색, 아이섀도 매트 48색·글로시 48색을 제공한다. 레드·핑크·코랄·오렌지·브라운/누드·플럼/버건디 계열을 필터로 고르며, 아이섀도는 블루/그레이와 그린/골드도 포함한다. 첫 화면부터 계열이 다양하게 보이도록 교차 배치한다.
- 점은 최대 3개다. 사진을 터치해 얼굴 안에 배치하고 드래그·화살표로 이동하며 크기·개별 삭제·점만 초기화·실행 취소를 지원한다. 새 사진에는 이전 점 위치와 해당 위치의 실행 취소 이력을 적용하지 않는다.
- 컬러 렌즈는 자연스러운 12색, 발색 강도, 테두리 진하기로 제공한다. 홍채 랜드마크와 눈꺼풀 영역을 사용해 합성하고 추정 동공 중심부와 원본의 밝은 반사광을 보호한다. 좌표가 불확실하면 렌즈만 제한한다.
- 블러셔는 기본 영역을 넓히고 범위를 조절할 수 있다. 피부 분할을 사용할 수 있으면 얼굴 피부 영역으로 제한한다.
- 아이라이너 꼬리 길이는 100%에서 기존 최대보다 길게 표현한다. 애교살 위치는 자동 기준 0%와 위쪽 범위를 유지하고 +100%에서 더 아래로 조절되도록 확장했다.
- 헤어 색상은 팔레트 선택과 적용 강도로 변경하며, 기기 내 머리카락 영역 분할 모델로 합성 범위를 구분한다.
- 사진 처리용 서버와 AI API 호출 없이 기기 내 모델 실행 및 그래픽 합성으로 구현한다. 웹 배포에는 정적 호스팅을 사용한다.

- 사진 확대 화면은 중앙 배치를 유지하고 50~400% 배율 버튼·두 손가락 핀치·확대 사진 이동을 제공한다. 배율 표시는 누르면 100%와 중앙 위치로 돌아간다. 보기 배율은 저장 이미지와 메이크업 설정에 영향을 주지 않는다.
- 사용 방법 버튼과 별도 내 사진 제목 행을 제거했다. 휴대폰 폭(600px 이하)에서는 확대·사진 바꾸기는 헤더 오른쪽, 실행 취소·전체 초기화는 사진 아래의 기존 배치를 유지한다. PC·태블릿에서는 실행 취소·전체 초기화를 팔레트 위 오른쪽에 배치한다. 좌우 배치에서는 사진 위 오른쪽의 확대·사진 바꾸기와 행을 맞추고, 위아래로 쌓이는 세로 태블릿에서는 팔레트 바로 위의 별도 오른쪽 정렬 줄에 둔다. 테두리 없는 텍스트와 44px 조작 영역을 유지한다. 같은 버튼을 옮겨 중복 노출을 막고 확대 화면에서는 전용 확대 도구를 사용한다. 모바일 조절 패널은 기본 40%이며 사진 크게·색상표 크게 버튼, 경계 손잡이 드래그와 키보드로 비율을 바꾼다.

- 눈 화장 확장 전 롤백 태그: before-eye-feature-expansion-20261125. PC·태블릿 편집 도구를 오른쪽 정렬한 상태를 기준으로 보관한다. 아이라이너 색상·눈썹 색상·속눈썹은 검토만 했으며 이 버전에 구현하지 않았다.

확장 과제
- 실시간 카메라 체험: 카메라 영상에서 얼굴 움직임을 추적하며 선택한 메이크업 효과를 적용한다. 정지 사진 기반 기능 구현 이후 진행한다.

진행 및 검증 과제
- UI 방향을 확정했고 사용자 사진의 기기 내 얼굴 인식, 피부·헤어 분할, 합성 코드를 연결했다.
- 얼굴 없음, 여러 얼굴, 크기 부족, 잘림, 큰 각도, 부위별 제한, 모델 오류, 재시도, 늦은 결과 취소를 처리한다.
- 모델과 실행 파일을 프로젝트에 저장하고 실제 브라우저에서 인식·분할·합성을 검증했다. 외부 API 호출이나 사진 업로드는 하지 않는다.
- 실제 사진에서 판정 임계값과 합성 품질을 검증한다. 가림을 항상 정확히 판별하는 기능은 아직 없다.
- 샘플 사진도 사용자 사진과 같은 실제 모델·합성 엔진을 사용한다. 기존 고정 마스크 데모는 제거했다.
- 실제 검증: 정면 인물 2종, 치아 영역 제외, 빈 이미지, 복수 얼굴, 작은 얼굴, 15도 기울임, 확대·비교·저장, 모바일 크기 화면.
- 다양한 사용자 사진 및 모바일 실기기에서의 판정과 품질 검증은 계속 필요하다.
