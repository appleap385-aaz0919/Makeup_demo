# ColorMatch · 컬러매치

정지 사진에서 파운데이션, 립스틱, 블러셔, 아이섀도, 아이라이너, 눈썹 색상, 속눈썹, 애교살, 컬러 렌즈, 점, 헤어 색상을 체험하는 웹 앱입니다.

- 공개 데모: https://appleap385-aaz0919.github.io/Makeup_demo/
- 얼굴 분석과 메이크업 합성은 브라우저에서 실행합니다. 사진을 서버로 업로드하거나 AI API를 호출하지 않습니다.
- 모델과 실행 파일은 `vendor/vision`에 포함되어 있으며 사이트에서 내려받습니다.
- 사진의 원래 색과 조명에 따라 결과가 달라집니다. 색상표는 실물 제품과 대응하지 않는 가상 색상입니다.
- 립스틱 48색, 블러셔 36색, 아이섀도 매트·글로시 각 48색을 계열별로 선택합니다. 아이섀도는 적용 강도와 상하·좌우 폭을 조절합니다.
- 아이라이너는 어두운 9색과 두께·길이·진하기·꼬리 방향을 제공합니다. 눈썹은 14색과 진하기를 선택하며 원래 털의 명암을 살립니다. 속눈썹은 ON/OFF와 두께·길이·진하기를 조절합니다.
- 헤어 24색·눈썹 14색에 허니·골든·베이지·애쉬·샴페인·플래티넘 블론드 6색을 공통으로 제공합니다. 헤어는 블론드 필터로 모아 볼 수 있으며, 밝은 색은 원본 명암에 따라 밝기를 조절합니다. 헤어와 눈썹의 적용 강도와 초기화는 독립적입니다.
- 눈 화장 안에서 6가지 기능을 개별 편집합니다. 휴대폰은 좁은 탭을 가로로 밀어 선택하고, 가장자리 표시로 남은 메뉴를 알립니다. PC·태블릿은 메뉴 6개를 두 줄로 표시합니다. 렌즈는 12색과 발색·테두리 진하기를 제공합니다.
- 첫 방문에는 실제 화면의 사진 바꾸기·전후 비교·편집 메뉴·이미지 저장 위치를 2페이지로 안내한 뒤 삼성 인터넷의 다크 모드 강제 적용 설정을 안내합니다. 로고 옆 느낌표로 처음부터 다시 볼 수 있습니다.
- 안내 노출 여부는 브라우저의 로컬 저장소에 보관합니다. 같은 브라우저·사이트에서는 재방문 시 자동 노출하지 않습니다. 사이트 데이터를 지우거나 다른 브라우저를 사용하면 다시 표시됩니다. 저장소를 차단한 환경에서는 방문 기록을 유지하지 못할 수 있습니다.
- 점은 피부 메뉴에서 최대 3개까지 사진에 배치하고, 드래그·화살표·크기·삭제로 조절합니다. 사진을 바꾸면 점 위치를 초기화합니다.

## 로컬 실행

Node.js를 설치한 뒤 `npm start`를 실행하고 http://127.0.0.1:4173/ 에 접속합니다. PowerShell에서는 `npm.cmd start`를 사용할 수 있습니다.

HTML 파일을 더블클릭하는 `file://` 방식에서는 모듈과 모델 로딩이 제한될 수 있으므로 HTTP 서버를 사용합니다. 이 서버는 정적 파일을 전달하며 사진을 분석하는 백엔드는 아닙니다.

## 배포

`main`에 푸시하면 `.github/workflows/pages.yml`이 앱과 테스트를 확인하고 GitHub Pages에 정적 파일을 배포합니다. 공개 사이트는 개발 PC가 꺼져 있어도 접속할 수 있습니다.

## 검증

- `npm run check`: JavaScript 구문 검사
- `npm test`: 사진 판정 로직 검사
- `npm run verify:ui`: 로컬 Chrome에서 UI 및 오류 복구 검사
- `npm run verify:real`: 실제 모델 및 렌더링 검사
- `COLORMATCH_URL` 환경 변수로 `verify:real`의 검사 주소를 지정할 수 있습니다.

브라우저 검증 스크립트의 Chrome 경로는 Windows 환경 기준입니다. 모바일 크기 검증은 실제 휴대폰/Safari 검증과 다릅니다. 애교살 위치는 명암 기반 추정이므로 수동 보정이 필요할 수 있습니다.

모델 및 SDK 출처와 라이선스는 `scripts/prepare-models.mjs` 및 `vendor/vision/LICENSE`를 참고하세요.

눈썹과 속눈썹 전용 AI 모델은 추가하지 않았습니다. 눈썹은 얼굴 좌표 안에서 어두운 털을 추정하고, 속눈썹은 위 눈꺼풀 곡선에 맞춰 합성합니다. 밝거나 희미한 눈썹, 원래 긴 속눈썹, 안경·앞머리 가림에서는 위치나 표현이 어색할 수 있습니다. 최대 속눈썹 설정은 기본값보다 화장한 느낌이 강합니다.

눈 화장 확장 전 상태는 Git 태그 `before-eye-feature-expansion-20261125`로 보관했습니다. 롤백은 해당 태그를 기준으로 새 복원 커밋을 만들어 배포합니다.

헤어 경계·블론드 개선 전 상태는 `before-hair-brow-refinement-20261125`로 보관했습니다. 기존 머리 분할 모델의 신뢰도와 원본 명암을 함께 사용해 경계를 혼합하고 피부로 판단한 영역을 보호합니다. 가는 잔머리·복잡한 배경·가림의 경계를 모두 정확히 구분하는 정밀 매팅 모델은 아니므로 강한 색상이나 높은 강도에서는 합성 흔적이 남을 수 있습니다.
